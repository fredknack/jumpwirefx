# jumpwirefx.com

Portfolio site for Fred Knack's interactive kiosk business, built with Next.js and deployed on Vercel.

## Develop

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test       # vitest
pnpm lint
pnpm build
```

## Content

Phase 1 content lives in `content/`:

- `content/site.ts` — headline, intro, contact details
- `content/projects.ts` — one entry per project (copy, skills, media paths)
- `content/media.json` — generated by `pnpm media`; video URLs and thumbnails

All pages read content through `lib/content.ts`, so a later CMS only changes that module.

## Media

`pnpm media` re-encodes the source videos in `_reference/` (not committed), writes poster
thumbnails to `public/media/<slug>/`, uploads MP4s to Vercel Blob, and writes
`content/media.json`. It needs `BLOB_READ_WRITE_TOKEN` in `.env.local`; pass `--no-upload`
to skip Blob.
