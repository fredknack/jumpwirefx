# jumpwirefx.com

Site for JumpWire, an interactive kiosk studio in Portland, Oregon, built with Next.js and deployed on Vercel.

## Develop

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test       # vitest
pnpm lint
pnpm build
```

## Content

Phase 1 content lives in `content/`:

- `content/site.ts` — headline, intro, contact details
- `content/projects.ts` — one entry per project (copy, skills, media paths)
- `content/media.json` — generated by `pnpm media`; video URLs and thumbnails

All pages read content through `lib/content.ts`, so a later CMS only changes that module.

## Media

`pnpm media` re-encodes the source videos in `_reference/` (not committed), writes poster
thumbnails to `public/media/<slug>/`, uploads MP4s to Vercel Blob, and writes
`content/media.json`. It needs `BLOB_READ_WRITE_TOKEN` in `.env.local`; pass `--no-upload`
to skip Blob.

## Admin (Phase 2)

Content lives in Neon Postgres when `DATABASE_URL` is set; otherwise the site reads the seed files in `content/`.

- `pnpm db:generate` – write a migration from `lib/db/schema.ts`; `pnpm db:migrate` applies it; `pnpm db:seed` loads `content/` into the database.
- `pnpm admin:hash` – prompts for the admin password (hidden, never on the command line) and prints the bcrypt hash for `ADMIN_PASSWORD_HASH`. It prints two forms: the raw hash for the Vercel dashboard or `vercel env add`, and a `.env.local` line with every `$` escaped as `\$`, because Next.js expands `$` in `.env` files even inside quotes.
- `AUTH_SECRET` – 32+ random characters (`openssl rand -base64 32`) used to sign the `jw_admin` session cookie (7 days).
- Sign in at `/admin/login`. Five wrong passwords from one IP block that IP for 15 minutes.
